# FastTT / TSX

FastTT is an AVX2 Shift-XOR erasure-code plugin for Ceph.

Installation, test commands, research plans, and results are maintained in
[the handoff document](docs/agent/fasttt-handoff.md).
The concise [FastTT-LRC design](docs/fasttt-lrc-design.md) explains the new scaffold.
Agents should read [AGENTS.md](AGENTS.md) first.
